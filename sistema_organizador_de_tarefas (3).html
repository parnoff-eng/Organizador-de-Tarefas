    Como funciona a sincronização entre usuários?

    Certifique-se de que todos os usuários entrem na mesma Sala com a senha correta. Qualquer tarefa criada, movida ou concluída aparecerá automaticamente em tempo real para todos.

    Se aparecer erro de "Banco Não Criado" ou "Permissão Negada":

    1. Abra o painel do seu projeto no Firebase Console: Abrir Firestore Console
    2. Clique em Criar banco de dados e escolha Iniciar no modo de teste.
    3. Na aba Regras (Rules), cole o código abaixo e clique em Publicar:
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
